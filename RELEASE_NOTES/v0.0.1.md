# v0.0.1

Initial pre-release.

## Features

- GitHub authentication via `gh` CLI
- Dashboard showing open pull requests across all repositories
- Review status badges (approved, changes requested, pending)
- CI check status per pull request
- Filtering by repository, author, and review status
- Sorting options for pull requests
- Settings page with per-user repo and team filters
- Packaged as a macOS `.dmg` installer
